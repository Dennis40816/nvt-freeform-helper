# Notch / Simulation Diagram Library

This folder is a layered visual map for the current Notch table calculation and Simulation paths.

- [中文圖庫](zh-TW/README.md)
- [English library](en/README.md)

The two libraries use the same structure:

- Overview: separates Notch table calculation from Simulation verification.
- Module maps: one map for Notch table, one map for Simulation.
- Detail diagrams: one diagram per module responsibility.

Canonical behavior remains documented in [Notch System Reference](../../reference/notch-system-reference.md). If a diagram and the canonical reference disagree, follow the canonical reference and update the diagram.
