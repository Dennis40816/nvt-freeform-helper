## T11 `N6` Edge Spill EN A/B 評估結論

### 現況
- 設定來源：`src/FreeformHelper.Application/Settings/MatchingSettings.cs` `EnableFreeformEdgeSpecialization`
- 演算法入口：`src/FreeformHelper.Application/Services/FreeformDetector.cs`
- UI 入口：`src/FreeformHelper.UI/Views/SettingsWindow.axaml` `Edge spill EN`
- 測試覆蓋：`tests/FreeformHelper.Tests/Application/Freeform/FreeformDetectorTests.cs`

### 結論
1. `Edge spill EN` 仍有必要保留。
2. 它解決的是「邊界 tiny spill 被全域 TH 壓掉」的案例，不是一般 freeform 判定。
3. 建議維持預設 `OFF`（保守），並把說明文改為「Boundary tiny spill specialization」避免誤解。

### A/B 驗證建議
1. A: `OFF`、B: `ON`，固定 `3635` + 同一組 TH。
2. 比較指標：`None->X/Y/XY` 轉換數、Step5 row 數、validation incoming/outgoing 差異。
3. 若 B 只在邊界 pad 增加有效 row，且無中間區域噪音擴散，才考慮升級預設。

## T12 `N3` CAD->Regular weighted allocation 設計草案

### 現況
- 既有權重計算：`src/FreeformHelper.Application/Services/NotchAllocationService.cs`
- 既有 target 分配：`src/FreeformHelper.Application/Services/NotchV22TargetAllocationService.cs`

### 草案（v2）
1. Candidate set:
   `overlapArea > epsilon` 且與 anchor IC 有有效關聯。
2. Base weight:
   `w0 = overlapArea / cadArea`（沿用現況，保持直覺）。
3. Boundary penalty:
   對非 boundary 或高 blocker 風險 pad 加懲罰係數 `p in [0,1]`。
4. Normalization:
   同 IC 內做 `w = (w0*p)/sum(w0*p)`，避免跨 IC 直接競爭。
5. Export rounding:
   最後才做百分比取整與飽和，保留 trace 原始浮點值供除錯。

### 需要新增的 trace 欄位
1. `baseWeight`
2. `penaltyFactor`
3. `normalizedWeight`
4. `roundingDelta`
