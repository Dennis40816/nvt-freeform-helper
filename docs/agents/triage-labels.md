# Triage labels

| Pocock role | GitHub label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待 maintainer 判定方向與優先級 |
| `needs-info` | `needs-info` | 缺少重現資訊、契約決定或 golden 簽核 |
| `ready-for-agent` | `ready-for-agent` | 規格、驗收與 blocker 已明確，可交由 agent 執行 |
| `ready-for-human` | `ready-for-human` | 必須由人員操作、審核或作產品／韌體決策 |
| `wontfix` | `wontfix` | 已明確決定不導入，issue 必須保留理由 |

功能工作可另加 GitHub 既有的 `enhancement`；錯誤修正可另加 `bug`。Lifecycle label 同一時間只保留最符合目前狀態的一個。
