# Triage labels

| Pocock role | GitHub label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Waiting for a maintainer to decide direction and priority |
| `needs-info` | `needs-info` | Missing reproduction information, contract decision, or golden sign-off |
| `ready-for-agent` | `ready-for-agent` | Spec, acceptance criteria, and blockers are clear; can be handed to an agent |
| `ready-for-human` | `ready-for-human` | Must be operated, reviewed, or decided on as a product or firmware decision by a person |
| `wontfix` | `wontfix` | Explicitly decided not to implement; the issue must keep the reason |

Feature work may additionally use GitHub's existing `enhancement` label; bug fixes may additionally use `bug`. Keep only the one lifecycle label that best matches the current status at any time.
